# Golden output files

Golden files in this directory are generated by running the test binary
in golden-generation mode and committing the output. In the default
comparison mode, the test binary links `commondata` (which includes
`calendarcore`) and compares its output against these golden files.

The 54 `.golden` files cover roundtrip, expansion and rule summaries for
18 fixtures. The expansion baselines record individual occurrences from
KCalendarCore between January 1, 2024 and December 31, 2028.

To generate candidate baselines, run the test binary with
`KERNEL_GOLDEN_GEN=1` and `KERNEL_GOLDEN_DIR` pointing to an existing output
directory. Compare the generated files with these baselines before copying
changes into this directory.

Regenerating is only appropriate after an intentional output change; the
comparison checks the event and recurrence payload against the frozen
literals. VTIMEZONE blocks are compared by TZID because transition
records come from the installed libical time-zone database.

Before comparing, `normalizeIcs()` in `src/golden_util.h` masks the
volatile lines PRODID, DTSTAMP, CREATED and LAST-MODIFIED. The timestamps
are wall-clock values emitted at parse time, so they differ on every run.
PRODID differs because this fork brands itself differently from upstream.

The roundtrip baselines compare normalized output. Dedicated tests verify that
imported times without a time zone are bound to the import time zone, and that
both imported and explicitly zoned events keep the same instant on reread.
