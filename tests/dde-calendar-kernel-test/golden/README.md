# Golden output files

Golden files in this directory are generated by running the test binary
in golden-generation mode and committing the output. In the default
comparison mode, the test binary links `commondata` (which includes
`calendarkernel`) and compares its output against these golden files.

Golden files are not included in this patch; they will be generated and
committed during the Stage 4 verification phase.

PRODID lines are exempt from byte comparison (see `prodidExempt()` in
`test_ics_roundtrip.cpp`).
